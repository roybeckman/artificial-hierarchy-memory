AHM 1.0 — MAP SKELETON TEMPLATE
Created by Roy Beckman, 2026

PURPOSE
This file is a visible AHM skeleton. It shows the AI — and the human reader — the map of the information before the details.

CORE IDEA
THE FILE TEACHES THE AI HOW TO READ THE FILE.
STRUCTURE GUIDES THE AI.
LANGUAGE CARRIES THE MEANING.
KEEP THE MEANING. REMOVE THE FLUFF.

INSTRUCTIONS
======================================================================
1. Read DESCRIPTION first.
2. Read KEY before interpreting compact codes.
3. Reconstruct objects and identities before drawing conclusions.
4. Follow explicit relations.
5. Preserve current, historical, uncertain and unresolved information.
6. Do not invent missing information.
7. Use STATE to understand the current situation.
8. Use NEXT to continue the work.
9. Preserve unknown local constructs even if they are not part of the common AHM core.
